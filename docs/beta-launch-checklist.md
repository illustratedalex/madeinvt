# MadeInVT Beta Launch Checklist

Invitation-only beta checklist for the first 10–20 maker accounts.

- [ ] New signup
- [ ] Email confirmation
- [ ] Login
- [ ] Forgot password
- [ ] Claim profile
- [ ] Approve claim
- [ ] Deferred owner linking
- [ ] Portal access
- [ ] Logout
- [ ] Mobile
- [ ] Production

## Deferred owner linking note

When a claim is approved before account creation, the platform links the owner record on later signup/login if the authenticated email matches the approved `claimant_email`. Pending and rejected claims are never auto-linked.
