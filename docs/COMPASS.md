# COMPASS

Compass is an editorial publishing platform for regional guides, maker publications, and community-driven storytelling.

## Compass Core

Compass Core includes:

- Authentication
- Analytics
- Relationship Graph
- Editorial Intelligence
- Newsroom
- Morning Briefing
- Business Directory
- Claims
- Partner Portal
- Traveler Experiences
- Collections
- Guides
- Search
- AI
- Notifications
- Publishing Workflow
- Media Library (future)

## Publications on Compass

### SouthernVT

- Publication type: Travel publication

## Compass HQ plan (internal only)

- The `/compass` route is intentionally disabled for now and should not be publicly accessible.
- Basecamp remains the active operational interface, now publication-aware across SouthernVT and MadeInVT.
- A future Compass HQ should launch only as an internal/admin surface after access controls, publication workflows, and readiness criteria are complete.
